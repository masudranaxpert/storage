API Integration Guide

Pass your token via header X-API-Key: sm_live_... or Authorization: Bearer sm_live_...

POST /api/v1/files (Ingest Video by URL) 
curl -X POST https://inclusion-hourly-matt-tuition.trycloudflare.com/api/v1/files \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"url": "https://cdn.example.com/video.mp4"}'
GET /api/v1/files/{key} (Status & Stream URLs) 
curl -X GET https://inclusion-hourly-matt-tuition.trycloudflare.com/api/v1/files/{key} \
  -H "X-API-Key: YOUR_API_KEY"
DELETE /api/v1/files/{key} (Single or Batch Delete) 
# Single key or comma-separated batch delete:
curl -X DELETE "https://inclusion-hourly-matt-tuition.trycloudflare.com/api/v1/files/key1,key2" \
  -H "X-API-Key: YOUR_API_KEY"
